# 🕵️ Projet-INTERACT for OSINT4FUN

This project is a **student-developed interactive web interface** designed to enhance the educational experience of the **OSINT4FUN** platform. Its goal is to transform the current text-based learning system into a more **immersive, intuitive, and engaging investigation environment** for beginners, students, and the general public.

Instead of interacting only through forms and text fields, users can now solve investigations through **realistic interactive modules**, making OSINT learning more practical and motivating.

---

## 🎯 Project Objectives

- Improve **user engagement and immersion**
- Make OSINT learning more **accessible to beginners**
- Transform static exercises into **interactive investigation scenarios**
- Add a layer of **gamification and realism**
- Keep full **compatibility with the existing OSINT4FUN platform**

---

## 🧩 Interactive Modules

The interface introduces several interactive components:

- 📱 **Fake mobile conversation interface** for realistic message-based investigations  
- 🗺️ **Interactive map** for geographic data input and spatial exploration  
- 🔐 **Safe dial module** for code-based challenges  
- 📅 **Interactive calendar** for timeline and date-related investigations  

More modules will be added as development continues.

---

## ⚙️ How It Works

This project acts as an **intermediate interface (proxy layer)** between the user and the OSINT4FUN platform:

1. The user interacts with the **custom interface**
2. The interface sends requests to the **Node.js backend**
3. The backend forwards the requests to **OSINT4FUN**
4. The responses are displayed through the interactive modules

This architecture allows OSINT4FUN to remain unchanged while significantly improving the user experience.

---

## 🛠️ Tech Stack

- **Frontend:** EJS, CSS, JavaScript  
- **Backend:** Node.js  
- **Architecture:** Proxy-based interaction layer
